# calc++

calc++ is my first C++ project, built while I'm learning programming from scratch.
I'm new to coding, so this project is mainly about learning by actually building something instead of only following tutorials.

## What I Applied & Learned

* **Loops** — `for`, `while`, and `do-while`
* **Functions** — creating reusable functions with parameters and return values
* **Function Return Types** — using `bool`, `int`, and `void` depending on what a function needs to return
* **Nested Menus & Conditions** — building the Prime Numbers submenu
* **Algorithms & Mathematical Logic** — Euclidean algorithm for GCD, LCM using GCD, prime checking, prime generation, and prime factorization
* **Type Casting** — converting `double` values to `int` where required
* **Code Reusability** — reusing `checkPrime()` inside `listPrimes()` and `customGCD()` inside `customLCM()`

### Main Goal

This project is being developed progressively rather than built all at once. The goal is to keep expanding the calculator while using each new feature to learn and apply a new C++ concept.

  
### The Goal

Calc++ is a work in progress.

My goal by the end of the year is to keep expanding it with **many more features**, making it much more capable than a basic calculator.
